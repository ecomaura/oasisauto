# Oasis Automotive Detailing Studio

Website for Oasis Automotive, Ulwe, Navi Mumbai. Static HTML, CSS and JavaScript, hosted on GitHub Pages.

Live: https://ecomaura.github.io/oasisauto/

## Editing

- `index.html`: all content (services, studio details, hours)
- `css/style.css`: colours are set once in `:root` at the top
- `js/main.js`: WhatsApp links, open/closed status, enquiry form
- `assets/`: logo, favicon, brand reel video

Phone number for WhatsApp is `WA_NUMBER` in `js/main.js`.
